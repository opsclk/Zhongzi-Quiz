# Project Blueprint: The 5 Faces of Zhongzi

## Overview

This project is a web application designed to showcase five different types of Zhongzi (rice dumplings). It has two main features:

1.  **Zhongzi Showcase:** A card-based gallery displaying the five types of Zhongzi, each with a description and a cute, illustrated character.
2.  **Personality Quiz:** An interactive, story-based quiz that determines which Zhongzi best represents the user's personality.

## Design and Features

### Visual Design

*   **Aesthetic:** Bright, cute, and cheerful. The UI is designed to be friendly and engaging, with a soft color palette, rounded shapes, and playful typography.
*   **Illustrations:** Each of the five Zhongzi types is represented by a unique, adorable illustration, giving them a distinct personality.
*   **Layout:** A responsive design that adapts to both desktop and mobile devices, with a clean and spacious layout.
*   **Styling:** Modern CSS with a focus on creating a fun and inviting user experience. This includes soft shadows, smooth transitions, and interactive button effects.

### Implemented Features

*   **Zhongzi Showcase:** A responsive grid of cards, each featuring a cute illustration, title, and description of a Zhongzi.
*   **Interactive Quiz:** A personality quiz that guides the user to their Zhongzi type.
*   **Dynamic UI:** The application flow is designed to be intuitive, starting with the quiz and then revealing the full showcase of Zhongzi characters.
